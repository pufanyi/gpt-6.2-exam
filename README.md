# 2026年普通高等学校招生全国统一考试 · 外语（GPT 语）

模仿中国高考新课标Ⅰ卷外语（满分 150 分，考试时间 120 分钟）真题排版的冷面讽刺试卷，由 **Antigravity × OpenAI Codex (`gpt-6.2-astra`)** 联合命题撰稿。全卷聚焦软件工程与 Codex 结对编程现场（辅以 Text 2 一箱梨一处点睛日常切片），以 100% 真题考务的克制冷面口吻，原汁原味考查当代 GPT / Codex 家族最具辨识度的工程口癖与行为特征（`SHA-256` 恋物癖、`收口 / 钉死 / 口径 / 落盘`、窄口径诚实、顺手越界、以及技术考古文中的 `气质 / 两个世界 / 采样哲学 / 时间语义 / 只是一条线索`）。

## 文件说明

- [`gaokao-exam.sty`](./gaokao-exam.sty)：教育部教育考试院（NEEA）高考真题风格 LaTeX 样式包（含左侧虚线弥封线与 **64 格 `考生信息 SHA-256` 填写栏**、各页页脚正文 `SHA-256`、`绝密 ★ 启用前` 标识、小标宋/黑体/仿宋/楷体混排、三选一与四选一自适应多栏对齐宏、完形与语法填空下划线宏、作文横线与读后续写段首格）。
- [`exam.tex`](./exam.tex) / [`exam.pdf`](./exam.pdf)：正式试题卷（8 页）。
- [`answer_key.tex`](./answer_key.tex) / [`answer_key.pdf`](./answer_key.pdf)：配套《参考答案及评分参考》（4 页，含第 1–45 题标准答案连续编码的 `SHA-256` 及非选择题同等给分组合摘要采信规则）。
- [`Makefile`](./Makefile)：一键编译脚本（自动兼容 `xelatex` 与 `tectonic`）。

## 随卷校验清单（SHA-256）

由于将文件自身的 `SHA-256` 写入文件并重新编译会改变文件字节，本卷采用双层校验口径：

1. **加印前基线摘要（印于试卷第 1 页《注意事项》第 5 条）**
   - `exam.tex`（加印前基线）：`586668fefcf0b9a9e6de1717f59ffcda5b385ace0cd10152fd3b377dbc703a87`
   - `exam.pdf`（加印前基线）：`a3e2d5f88a19fe5a86495422f1213dc06c648e935bff37a915471c720d94a584`
2. **加印重编后的成卷文件字节摘要（可直接用 `sha256sum` 核对）**

```text
1c39619d5ad63ff8b4a7a0d00ce8b5d5eba495be0653449dc56791409b52d056  exam.tex
c268e351b965e00626ee966efa308083de44030f0818b7d98643160605d7d813  exam.pdf
3211bca11d6c4a29f87fe8e48f24424705136147c460f7c13bc2c2a7268e14b5  answer_key.tex
4b5c7724fd1287a445fb68e15e031fa1cb6490e41aaed57685f919c6c0eeca3c  answer_key.pdf
a538b5c1853d20b692ccb8c56508bb69e887641ce9c07061382b346807cca32f  gaokao-exam.sty
```

3. **各页页脚 `本页正文 SHA-256` 计算口径**
   - `exam.pdf`（共 8 页）与 `answer_key.pdf`（共 4 页）每页底部均印有当页正文的 `SHA-256` 摘要。
   - 计算范围：取当页 PDF 文本（PDFium 提取顺序），剔除左侧弥封线文字与底部两行页脚（页码行及 `本页正文 SHA-256` 行），去除全部空白字符后按 UTF-8 编码计算 `SHA-256`。因页脚摘要自身不纳入输入，写入真实摘要重编后各页正文摘要保持不动点一致。
4. **考生交卷 `SHA-256` 核验口径（印于试卷第 1 页《注意事项》第 3–4 条及参考答案首页）**
   - 第 1–45 题标准答案连续编码（`BACBACBCABCADBCADBACBDCABFCAGDBDACBADCBADCADB`）的 `SHA-256` 为 `0ad9b5b9fb328591d9b4f58fb91fa72df051844c1f369fde9a1d8865d9b91e5a`。
