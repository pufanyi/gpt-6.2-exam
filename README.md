# 2026年普通高等学校招生全国统一考试 · 外语（GPT 语）

模仿中国高考新课标Ⅰ卷外语（满分 150 分，考试时间 120 分钟）真题排版的冷面讽刺试卷，由 **Antigravity × OpenAI Codex (`gpt-6.2-astra`)** 联合命题撰稿。全卷摒弃互联网大厂周报黑话与小品式夸张叠甲，全程保持真题考务的克制冷面口吻，原汁原味呈现并考查 `GPT-6.2-Astra` 世代最具辨识度的真实语言习惯。

## 文件说明

- [`gaokao-exam.sty`](./gaokao-exam.sty)：教育部教育考试院（NEEA）高考真题风格 LaTeX 样式包（含左侧虚线弥封线、`绝密 ★ 启用前` 标识、小标宋/黑体/仿宋/楷体混排、三选一与四选一自适应多栏对齐宏、完形与语法填空下划线宏、作文横线与读后续写段首格）。
- [`exam.tex`](./exam.tex) / [`exam.pdf`](./exam.pdf)：正式试题卷。
- [`answer_key.tex`](./answer_key.tex) / [`answer_key.pdf`](./answer_key.pdf)：配套《参考答案及评分参考》（含逐题冷面证据链解析、语法填空验证边界给分细则、应用文双版本范文及评注、读后续写范文与“换蓝饭盒/旧车票即扣分”五档评分标准）。
- [`Makefile`](./Makefile)：一键编译脚本。

## 编译方式

需安装 `TeX Live`（含 `xelatex`、`ctex` 及中文字体）：

```bash
make
```

或手动执行两次 `xelatex`（以确保总页数引用 `\pageref{LastPage}` 准确）：

```bash
xelatex exam.tex && xelatex exam.tex
xelatex answer_key.tex && xelatex answer_key.tex
```
